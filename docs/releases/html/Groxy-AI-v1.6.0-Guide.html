What Groxy AI v1.6.0 Delivers in Plain English: Operators can now ask Groxy in plain conversation to refine a single section of a Grex Theme Builder page (for example, “make this hero calmer, keep one primary button, and tighten spacing”) without regenerating the whole page or touching sibling sections. Every proposal is checked against the Golden-Ratio Design-Craft Playbook, Light and Dark WCAG AA contrast, exact ADR-025c numbers, and the 22-rule Grade A/A+ gate, then shown as a side-by-side diff before applying via one-click undoable applyAiLayout.

1. Iterative Section Co-Pilot (POST /api/groxy/section-refine & /apply)

  • Targeted Subtree Isolation (C1): Resolves section_id using Builder semantics (node.id else node.props.id), rejecting missing IDs (404), duplicate IDs (422), and structural nodes (Fragment, TemplatePart, slot root). Every sibling section and ancestor stays byte-for-byte identical.
  • Human-in-the-Loop Diff & Single-Use rtok_<hex> Ledger (C2, C8): Stages a side-by-side text and structural diff with an approval token hashed in SQLite (groxy_section_refine_ledger). If a human edits any sibling section between propose and apply, apply returns 409 SECTION_SLOT_DRIFT instead of overwriting their work.
  • One-Slot Dispatch & 1-Click Undo (C3): Concurrent apply races resolve atomically (one 201 winner, 409 losers/replays, 403 mismatches). The winner dispatches strictly via one-slot POST /api/mcp/layout (actor: "groxy-ai"), verifies readback digest parity, and preserves 1-click Ctrl+Z applyAiLayout undo.
  • Local-First Modes: Runs deterministically offline with zero API fees by default, with optional local Ollama (127.0.0.1:11434) offline fallback or GRAB-E402 SSRF-allowlisted HTTPS BYOK enrichment.

2. Golden-Ratio Design-Craft Playbook (playbook/design-craft.v1.json)

Rule ID Family What It Checks & Repairs
GROXY-CRAFT-001 Spacing Rhythm Enforces 8pt spacing via live --grex-* tokens (4pt allowed only for tight inline pairs) and snaps off-grid values to the nearest live 8pt token.
GROXY-CRAFT-002 Line Measure Targets 60–65ch readable body copy via live measure tokens; reports token_unavailable if missing (C4) instead of inventing tokens or hardcoding 65ch.
GROXY-CRAFT-003 CTA Hierarchy Allows at most one primary CTA per fold and deterministically demotes extra primary CTAs to secondary.
GROXY-CRAFT-004 Surface Elevation & Contrast Checks Light/Dark --grex-surface-1 / --grex-surface-2 (reporting token_unavailable if absent) and repairs Light/Dark contrast to WCAG AA >= 4.5:1 (C6).
GROXY-CRAFT-005 Full-Stack CMS Wiring Binds ForEach grids and Form inputs strictly to live GrabLab CMS types/fields with exact ADR-025c strings and never fabricates form action URLs (C7).
