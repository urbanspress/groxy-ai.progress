2. Hardened --read-only Production Hosting (deploy/)

  • Immutable Container Root Filesystem: deploy/docker-compose.yml enforces read_only: true, cap_drop: ["ALL"], no-new-privileges:true, and tmpfs: /tmp:rw,noexec,nosuid,size=64m with loopback port binding (127.0.0.1:8090:8090) behind Caddy or Nginx TLS.
  • Scoped Writable Mounts: Only ../storage:/app/storage:rw (for SITE-CONTEXT.md) and ../cache:/app/cache:rw are writable; source files, templates, playbook rules, and Grex JS assets remain read-only.
  • Two Ready Modes: Standalone groxy-ai by default, or full 4-layer stack (docker compose -f deploy/docker-compose.yml --profile ecosystem-stack up -d) alongside grablab-cms (v1.0.1) and grex-builder-studio (v1.0.0).
