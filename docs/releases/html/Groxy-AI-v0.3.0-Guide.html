Release Series: Post-1.0 Step 4 • Runtime: GRAB v1.1.0 + Grex JS v1.0.0 • SemVer Tier: Pre-1.0 Feature Release

What Groxy AI v0.3.0 Adds in Plain English: Designers and content authors can now compose complete landing pages or modular page sections (Hero Sections, Pricing Grids, FAQ Accordions, and dynamic ForEach showcases) by picking a curated visual Style Pack, target slot, and topic. Every generated section automatically inherits your site’s live --grex-* colors and .grex-c-* utility classes from GRAB-DESIGN-SYSTEM.md, enforces zero wrapper <div> tags and exact GrabDecimal pricing, verifies a Grade A/A+ WCAG AA scorecard before previewing, and waits for your single-use approval before dispatching to Grex Theme Builder with 1-click Ctrl+Z Undo support.

  • 4 Design Style Packs: emerald-editorial (Emerald Editorial), obsidian-tech (Obsidian Developer Studio), warm-commerce (Warm Precision Commerce), and swiss-minimal (Swiss Grid Minimal).
  • 5 Semantic Blueprints: full_landing_page, hero_section, pricing_grid, faq_accordion, and foreach_showcase built purely from the 20 approved grex.elements.json components.

3. Human-in-the-Loop Preview, MCP Dispatch & 1-Click Undo

  • Non-Mutating Studio Preview (POST /api/groxy/generate-layout): Renders an interactive zero-<div> live preview canvas, hierarchical semantic node tree inspector, applied --grex-* / .grex-c-* badges, and 4-pillar scorecard in /groxy without writing to GrabLab CMS or Grex Theme Builder.
  • Single-Use Token Dispatch (POST /api/groxy/generate-layout/apply): Requires valid X-CSRF-Token plus the single-use approval_token (403 invalid, 409 replay). Dispatches to Grex Theme Builder POST /api/mcp/layout with actor: "groxy-ai" and records a reversible applyAiLayout command stack entry for 1-click Undo restoration.
  • Draft-Only CMS Persistence (GROXY-SAFE-001): When creating a companion entry in GrabLab CMS via create_entry_draft, inspects live type field definitions and strictly enforces status_enforced: "draft".
